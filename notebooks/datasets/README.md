# Vendored task data

`present-past-future.json` — 206 `{input, past, future}` verb triples, copied
verbatim from
[kayleeisokay/natural_language_autoencoders](https://github.com/kayleeisokay/natural_language_autoencoders)
(`notebooks/datasets/present-past-future.json`), which is **Apache-2.0**. The
`input`/`past` pairs derive from Todd et al. 2023's function-vector datasets
(`dataset_files/abstractive/present-past.json`); the `future` column is that
repo's addition.
